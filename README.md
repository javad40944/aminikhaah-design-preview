# پیش‌نمایش طراحی جامع سایت امینی‌خواه

این مخزن فقط برای نمایش و بازبینی طراحی آزمایشی رابط کاربری سایت امینی‌خواه است.

- پیش‌نمایش اصلی و تنها ورودی پروژه: `index.html`
- مقایسه سه جهت بصری در همان صفحه اصلی و از منوی «هویت بصری» انجام می‌شود:
  - A — سپیده و زیتون
  - B — لاجورد و خورشید
  - C — انار و کاغذ
- هر انتخاب روی تمام ۱۲ نمای طراحی اعمال می‌شود؛ حالت روز/شب و اندازه نمایشگر نیز در همان صفحه قابل تغییر است.
- منبع طراحی: اسناد اصلی پروژه در Google Drive و فایل‌های HTML کاربر؛ Google Stitch منبع مکمل است.
- داده‌ها و تصاویر پیش‌نمایش نمایشی‌اند؛ این نسخه به سایت زنده، Backend یا پایگاه داده متصل نیست.
- انتشار این مخزن به‌معنای تغییر یا انتشار سایت aminikhaah.ir نیست.
- فایل‌ها و تغییرات در همین مخزن نگهداری می‌شوند؛ برای مقایسه سبک‌ها صفحه یا فایل جداگانه ساخته نمی‌شود.

## دسترسی عمومی

این مخزن و GitHub Pages عمومی‌اند. هیچ رمز عبور، کلید API یا فایل خصوصی در آن قرار ندهید.
