# پیش‌نمایش طراحی جامع سایت امینی‌خواه

این مخزن صرفاً برای نمایش آنلاین و دریافت بازخورد درباره **طراحی آزمایشی رابط کاربری سایت امینی‌خواه** است.

- نسخه: طرح جامع تعاملی ۱ (پیش‌نویس برای تأیید)
- منبع اصلی: Google Drive شخصی پروژه، سند مادر و فایل HTML نسخهٔ ۰۲
- فایل انتشار: `index.html` با CSS و JavaScript داخلی
- محدودیت: داده‌های نمایشی، بدون اتصال به سایت اصلی، بدون صوت واقعی و بدون اجرای Backend
- وضعیت: طرح بصری، رنگ‌های نهایی و جزئیات صفحات هنوز مصوب نیستند.
- انتشار طرح در این مخزن **به‌معنای انتشار یا تغییر سایت aminikhaah.ir نیست**.

## ویرایش‌های بعدی

بازنگری‌ها در همین `index.html` انجام می‌شود و تاریخچه نسخه‌ها در Git حفظ خواهد شد. تصمیم‌ها و گزارش پیشرفت در سند مادر Drive ثبت می‌شوند.

## دسترسی عمومی

این مخزن و پیش‌نمایش GitHub Pages **عمومی** است؛ هیچ فایل خصوصی یا رمز عبوری در آن قرار ندهید.
