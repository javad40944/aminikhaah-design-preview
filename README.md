# پیش‌نمایش طراحی جامع سایت امینی‌خواه

این مخزن فقط برای نمایش و بازبینی طراحی آزمایشی رابط کاربری سایت امینی‌خواه است.

- فایل اصلی و تنها صفحه پیش‌نمایش: `index.html`
- تمام اصلاحات و مقایسه‌ها در همین صفحه ادغام می‌شوند؛ برای هر اصلاح صفحه مستقل ساخته نمی‌شود.
- دوازده نمای محصول در یک پیش‌نمایش قابل پیمایش نگهداری می‌شوند.
- سه جهت بصری A «سپیده و زیتون»، B «لاجورد و خورشید» و C «انار و کاغذ» از منوی «هویت بصری» قابل انتخاب‌اند.
- طراحی مرحله ۰۸ شامل ساختار خانه و ناوبری، جست‌وجوی تفکیکی، آلبوم و جلسه، رسانه، موضوعات، حساب کاربری، دیدگاه‌ها و پلیر پایدار است.
- پلیر نمونه کنترل‌های قبلی/بعدی، پرش ۱۰ ثانیه‌ای، سرعت، صف و نمای تمام‌صفحه دارد؛ هیچ صوت یا ویدئوی واقعی در این پیش‌نمایش پخش نمی‌شود.
- بخش‌هایی که به داده یا توسعه Backend نیاز دارند با برچسب «نیازمند توسعه بعدی» مشخص شده‌اند.
- داده‌های نمایشی جایگزین داده واقعی نیستند؛ متن جلسه و آمار حساب فقط پس از اتصال به منبع معتبر نمایش داده می‌شوند.
- این نسخه هنوز پیش‌نویس بازبینی است؛ انتخاب نهایی هویت بصری و تصویب طراحی جامع کاربر باقی مانده است.
- منبع طراحی: اسناد Word و HTML اصلی در Google Drive پروژه؛ Google Stitch فقط منبع مکمل است.
- سایت زنده aminikhaah.ir، Backend و GitLab سازمانی از این مخزن مستقل‌اند و با انتشار پیش‌نمایش تغییر نمی‌کنند.

## دسترسی عمومی

این مخزن و GitHub Pages عمومی‌اند. هیچ رمز عبور، کلید API یا فایل خصوصی در آن قرار ندهید.
